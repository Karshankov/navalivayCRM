# Бета-тестирование мини-аппы (команда)

## Схема

| Что | Где | Кто видит |
|---|---|---|
| Прод (основная сборка) | `https://navalivay.store/` | все клиенты (кнопка меню бота) |
| Бета (новая сборка) | `https://navalivay.store/beta/` | только команда, по прямой ссылке |

Сервер, БД, бот и уведомления — общие: бета работает с реальными заказами,
бонусами и Telegram-уведомлениями. Разделён только фронтенд.

## Раскатить бету (после коммита в master)

```bash
cd /var/www/NAVALIVAY
bash ops/deploy-beta.sh <полный-SHA>     # сборка с base=/beta/ в dist-beta
```

Открыть `https://navalivay.store/beta/` — отправить ссылку в чат команды.
Telegram открывает её как mini app (домен привязан к боту), initData
подписывается тем же ботом: авторизация, заказы и уведомления настоящие.

## «Выпустить всем»

```bash
cd /var/www/NAVALIVAY
./ops/prod.sh deploy <полный-SHA>        # тот же SHA становится основной сборкой
```

После этого `/` и `/beta/` совпадают — все клиенты видят новое.

## nginx

`location /beta/` уже в копии `ops/nginx.conf`; на сервере добавлялся руками
(как SSE-локейшн). index.html беты — no-store (свежий при каждом заходе),
ассеты — по хэшу с immutable-кэшем.

## Откат беты

Бета не затрагивает прод: перезалить прежний SHA (`deploy-beta.sh <старый-SHA>`)
или удалить `location /beta/` из nginx. Клиенты ничего не заметили в любом случае.
