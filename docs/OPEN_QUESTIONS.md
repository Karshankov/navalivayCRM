**Контекст:** Изучены таблицы `orders`, `order_items`, API endpoints в `public.js`, но не полностью ясен полный жизненный цикл.

**Вопросы:**

   - Есть ли другие статусы? (например, `cancelled`, `pending_payment`, `ready`)
   
2. В какой момент списываются остатки товаров со склада?

3. Когда именно рассчитывается и фиксируется прибыль (`profit`)?
   - При создании заказа?
   - При изменении статуса?
   - При редактировании заказа клиентом или менеджером?
   
4. Как работает редактирование заказа клиентом?

   - Возвращаются ли остатки при изменении состава?
   - Пересчитываются ли лояльность и промокоды?
