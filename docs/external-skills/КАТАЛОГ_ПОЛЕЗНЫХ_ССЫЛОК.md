## Как читать пометки

- **БЕСПЛАТНО** — основной описанный инструмент или материал доступен без оплаты; ограничения лицензии и региона сохраняются.
- **ЕСТЬ БЕСПЛАТНЫЙ ДОСТУП** — бесплатная часть, тариф или квота; расширенные функции могут оплачиваться.
- **БЕСПЛАТНЫЙ КОД / ВЕСА** — можно получить исходники или веса, но API, сервер, GPU и лицензии отдельных моделей могут требовать расходов.
- **ПЛАТНО** — продукт, оборудование или вычисления требуют оплаты.
- **ПРОБНЫЙ ДОСТУП / ГРАНТ** — временные кредиты или экспериментальный доступ, не постоянная бесплатная услуга.
- **УСЛОВИЯ ТРЕБУЮТ УТОЧНЕНИЯ** — тариф, лицензия или доступ не подтверждены однозначно; не считать бесплатным решением для бизнеса.
- **СПРАВОЧНЫЙ МАТЕРИАЛ** — документация или подборка; её бесплатное чтение не делает описанные сервисы бесплатными.

## Как использовать каталог с ИИ-агентом

Скачайте эту MD-шку, добавьте её в проект или базу знаний агента и напишите, например:

> Сначала ищи подходящие решения в каталоге полезных ссылок. Подбери 3–7 вариантов под мою задачу. Для каждого коротко объясни, зачем его открывать и какие ограничения учитывать. Если в каталоге ничего подходящего нет или сведения могли устареть — выполни поиск в интернете и проверь официальный источник.

Примеры запросов:

- «Подбери шесть сайтов, где посмотреть интересный дизайн финансового приложения».
- «Найди готовые анимации и компоненты для современного лендинга».
- «Подбери открытые инструменты для анализа акций и финансовых исследований».
- «Найди сервис для создания рекламного ролика по изображениям».
- «Подбери инструменты Google для маркетинга и дизайна и укажи ограничения бесплатного доступа».

## Безопасность VPS и защита от брутфорса

- [Fail2Ban](https://github.com/fail2ban/fail2ban) — **БЕСПЛАТНЫЙ КОД / ВЕСА.** классическая защита от перебора: читает журналы, обнаруживает повторные неудачные входы и временно блокирует IP через firewall. Подходит как простой вариант для одного VPS. Не заменяет SSH-ключи и отключение парольного входа.
- [CrowdSec](https://github.com/crowdsecurity/crowdsec) — **БЕСПЛАТНЫЙ КОД / ВЕСА.** обнаруживает атаки по журналам и использует коллективную репутацию вредоносных IP. Сам движок только принимает решения; для реальной блокировки нужен подходящий [firewall bouncer](https://docs.crowdsec.net/u/bouncers/firewall/) для `iptables` или `nftables`.
- [endlessh-go](https://github.com/shizunge/endlessh-go) — **БЕСПЛАТНЫЙ КОД / ВЕСА.** необязательная SSH-ловушка: удерживает автоматических ботов в очень медленном соединении. Это дополнительный honeypot, а не основная защита; перед использованием настоящий SSH нужно безопасно перенести с порта 22 и проверить firewall.

### Пример базовой защиты публичного VPS

- SSH принимает вход только по ключу; парольная и интерактивная аутентификация отключены.
- Вход `root` по паролю запрещён. Более строгий вариант — отдельный пользователь с `sudo` и полное отключение удалённого входа `root` после проверки резервного доступа.
- Host firewall включён: входящие соединения по умолчанию запрещены, исходящие разрешены.
- Снаружи открыты только необходимые порты: обычно `22/tcp` для SSH и `80,443/tcp` для Nginx, одинаково для IPv4 и IPv6.
- Базы данных и внутренние приложения слушают `127.0.0.1`, а публичный доступ к веб-приложениям проходит через Nginx.
- Для дополнительного автоматического бана выбирают Fail2Ban или CrowdSec; устанавливать оба сразу обычно не требуется.

Проверено 26 августа 2026 года по официальным репозиториям и документации проектов.

## Правила безопасного использования

- Бесплатный сервис почти всегда означает квоты, очередь, водяной знак, испытательный режим или ограничения по странам.
- Открытый код не означает бесплатную эксплуатацию: могут понадобиться платные модели, данные, программные интерфейсы или серверы.
- Не загружайте клиентские базы, персональные данные, ключи доступа и коммерческие секреты в экспериментальные сервисы без проверки условий.
- Не копируйте фирменный стиль известного бренда буквально: используйте примеры как направление и адаптируйте под свой продукт.
- Для коммерческого проекта отдельно проверяйте права на код, изображения, шрифты, музыку и созданные материалы.
