# Чеклист: тестирование отзывов на проде

Инструкция для самостоятельной проверки после деплоя (Костя и команда).

## Два режима в CRM → Отзывы → Настройки

| Режим | Кого затрагивает | Когда использовать |
|-------|------------------|-------------------|
| **Список тестировщиков** (`qa_active` + юзернеймы) | Только перечисленные @username | **Основной путь** — проверка для `rk0ff` и демо-persona |
| **Тестовый режим отзывов** (чекбокс внизу) | **Все** покупатели | Только если whitelist не хватает; выключить сразу после прогона |

Whitelist даёт тем же пользователям bypass кулдауна и ограничений покупки при отправке отзыва (как глобальный тестовый режим, но точечно).

## Быстрый старт (5 шагов)

1. CRM → **Отзывы** → таб **Настройки**
2. Вписать `rk0ff` в поле юзернеймов
3. Включить «Разрешить тестирование выбранным пользователям» → **Сохранить** (подтвердить в модалке)
4. Открыть **Telegram Mini App** под аккаунтом @rk0ff
5. После проверки — **«Выключить тестирование»** в жёлтом баннере вверху страницы

## Полный прогон сценариев A–G

### Подготовка (admin)

1. Настройки → **Засеять демо-сценарии** (confirm)
2. Добавить в whitelist:
   ```
   rk0ff
   review_demo
   review_pending
   review_cooldown
   review_optout
   ```
3. Включить whitelist → Сохранить

### Клиент (Telegram Mini App)

| ID | Аккаунт | Что проверить |
|----|---------|---------------|
| A | `review_demo` (900000001) | Dock «Оцените заказ» → деталь заказа → форма отзыва |
| B | `review_pending` | «На модерации» на 1-й линейке + форма на 2-й |
| C | `review_cooldown` | Кулдаун на 1-й, форма на 2-й |
| D | `review_optout` | Dock скрыт; в профиле opt-out включён |
| E | без мока / любой | Каталог → ★ на линейке → модалка с ответом менеджера |

Локально сценарии A–D также доступны через `http://localhost:5173/dev-review-test.html` и dev mock.

### CRM

| ID | Где | Что проверить |
|----|-----|---------------|
| F | Заказы | Badge pending, плашка розыгрыша |
| G | Отзывы → Модерация / Ответы / Розыгрыш | Approve/reject, ответ менеджера, 5 победителей |

Если плашка розыгрыша не видна:

```js
localStorage.removeItem('crm_ack_draw_id');
location.reload();
```

## Завершение

1. Баннер → **Выключить тестирование** (сбрасывает whitelist и глобальный тестовый режим)
2. Убедиться, что жёлтый баннер исчез
3. При необходимости очистить поле юзернеймов и сохранить
