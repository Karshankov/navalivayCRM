# Обновление экрана авторизации

## Изменения

### Описание
Заменён стандартный экран авторизации с полями "Логин" и "Пароль" на компонент `AdminLockScreen`, который использует единое поле для ввода лицензионного ключа (фактически - пароля без логина).

### Что изменено

1. **AdminView.vue**:
   - Удалён старый блок авторизации с формой логина и пароля (строки 4-32)
   - Заменён на использование компонента `AdminLockScreen` для неавторизованных пользователей
   - Функция `handleLogin()` заменена на `handleLoginSuccess()`
   - Удалена переменная `loginForm`
   - Удалены неиспользуемые CSS стили для старого экрана авторизации

2. **AdminLockScreen.vue**:
   - Обновлены тексты в зависимости от режима (авторизация/разблокировка):
     - Заголовок: "Авторизация" (при входе) или "Доступ заблокирован" (при блокировке)
     - Кнопка: "Войти" (при входе) или "Разблокировать" (при блокировке)

### Логика работы

Компонент `AdminLockScreen` поддерживает два режима:

1. **Режим авторизации** (`isLoginMode = true`):
   - Отображается когда `!adminStore.isAuthenticated`
   - При вводе лицензионного ключа вызывается `adminStore.login()` с username='admin' и введённым паролем
   - После успешной авторизации эмитируется событие `unlocked`

2. **Режим разблокировки** (`isLoginMode = false`):
   - Отображается когда пользователь авторизован и нажал кнопку "Блокировка"
   - При вводе лицензионного ключа вызывается `crmStore.verifyProfitPassword()`
   - После успешной разблокировки эмитируется событие `unlocked`

### Преимущества

- Единообразный интерфейс для авторизации и разблокировки
- Красивый дизайн с градиентами и анимациями
- Использование лицензионного ключа вместо пары логин/пароль
- Автофокус на поле ввода
- Чёткие сообщения об ошибках
